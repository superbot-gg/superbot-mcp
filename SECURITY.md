# Security policy

This repository holds the public descriptors for superbot, your own AI agent, made by EZO Labs Inc.

## Report a vulnerability

Email security@ezolabs.io. That is the security contact superbot publishes at https://superbot.gg/.well-known/security.txt. For anything that is not a vulnerability, the same file lists contact@ezolabs.io.

Please include what you found, the steps to reproduce it, and the file or endpoint it concerns. Do not open a public issue for a vulnerability.

## What is in scope

- The manifests and the skill in this repository.
- The superbot service at https://superbot.gg and https://api.superbot.gg.
